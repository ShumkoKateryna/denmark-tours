# Настройка отзывов (Firebase)

Отзывы хранятся в бесплатной облачной базе Google Firebase (Firestore) и видны всем посетителям сайта. Пока Firebase не настроен, на сайте показывается сообщение «Раздел отзывов скоро откроется», а форма скрыта — ничего не сломается.

## Шаг 1. Создайте проект Firebase

1. Откройте https://console.firebase.google.com и войдите с Google-аккаунтом.
2. Нажмите **«Создать проект»** (Create a project), назовите его, например, `denmark-tours`.
3. Google Analytics можно отключить — он не нужен.

## Шаг 2. Создайте базу данных Firestore

1. В меню слева: **Build → Firestore Database → Create database**.
2. Регион: выберите `europe-west3` (Франкфурт) или любой европейский.
3. Режим: **Production mode**.

## Шаг 3. Настройте правила безопасности

Во вкладке **Rules** замените содержимое на это и нажмите **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /reviews/{reviewId} {
      allow read: if true;
      allow create: if
        request.resource.data.keys().hasOnly(['name', 'route', 'rating', 'text', 'createdAt'])
        && request.resource.data.name is string
        && request.resource.data.name.size() >= 1
        && request.resource.data.name.size() <= 60
        && request.resource.data.route is string
        && request.resource.data.route.size() <= 60
        && request.resource.data.rating is int
        && request.resource.data.rating >= 1
        && request.resource.data.rating <= 5
        && request.resource.data.text is string
        && request.resource.data.text.size() >= 10
        && request.resource.data.text.size() <= 1000
        && request.resource.data.createdAt == request.time;
      allow update, delete: if false;
    }
  }
}
```

Эти правила разрешают всем читать отзывы и добавлять новые (с проверкой полей), но запрещают изменять и удалять их через сайт.

## Шаг 4. Получите конфигурацию для сайта

1. В консоли Firebase: шестерёнка вверху слева → **Project settings**.
2. Внизу, в разделе **Your apps**, нажмите иконку **`</>`** (Web).
3. Назовите приложение (например, `site`), Firebase Hosting подключать не нужно.
4. Скопируйте объект `firebaseConfig` — он выглядит так:

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "denmark-tours.firebaseapp.com",
  projectId: "denmark-tours",
  storageBucket: "denmark-tours.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};
```

## Шаг 5. Вставьте конфигурацию в reviews.js

Откройте файл `reviews.js` и замените блок `firebaseConfig` в начале файла (там, где значения `YOUR_...`) на скопированный. Сохраните и загрузите файл на хостинг.

Готово — форма появится на сайте, отзывы будут сохраняться и показываться всем.

## Как удалить нежелательный отзыв

В консоли Firebase: **Firestore Database → коллекция `reviews`** — найдите документ с отзывом и удалите его. Изменения появятся на сайте после обновления страницы.

## Примечания

- Бесплатного лимита Firebase (50 000 чтений в день) для сайта экскурсий хватит с большим запасом.
- Ключ `apiKey` в коде сайта — это нормально: он не секретный, доступ ограничивают правила из шага 3.
